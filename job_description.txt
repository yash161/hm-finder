Responsibilities
Build and improve services, infrastructure, and developer tooling that power continuous integration, ephemeral environments, and automated testing across Upstart
Develop scalable Kubernetes- and AWS-based capabilities that enable engineers to create and use production-like environments through reliable, self-service workflows
Build shared infrastructure for test execution, orchestration, environment setup, and results to provide engineers with fast, trustworthy feedback during development and continuous integration
Improve platform reliability, performance, observability, and cost efficiency by diagnosing recurring issues and implementing durable software and infrastructure improvements
Replace manual or fragmented developer workflows with reusable APIs, automation, and platform capabilities that simplify common development tasks
Use AI throughout software development and problem solving, and identify opportunities for AI-enabled workflows and capabilities that improve developer productivity across Upstart

Required
Bachelor's degree in Computer Science, Engineering, Mathematics, or a related field (or its equivalent), plus 3 years of professional software engineering experience
Experience developing production software using one or more general-purpose programming languages
Experience designing, building, testing, and operating production software or infrastructure
Experience working with cloud infrastructure, distributed systems, continuous integration systems, developer tooling, or backend services
Experience independently delivering well-scoped software engineering projects from technical design through production operation
Demonstrated experience using AI assisted development tools across multiple stages of the software engineering lifecycle, with an interest in continuously evolving how you use these tools as their capabilities advance
Preferred
Experience with Kubernetes control-plane engineering, AWS, containers, or infrastructure as code
Knowledge of developer tooling, continuous integration systems, internal developer platforms, or shared test infrastructure
Experience building or operating ephemeral or production-like development and testing environments
Experience building APIs, services, command-line tools, test orchestration, or automation used by other engineers
Experience using AI-assisted development tools across the software engineering lifecycle or building AI-enabled developer workflows and automation
